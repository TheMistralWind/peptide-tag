# Bundled fonts

Both are SIL Open Font License 1.1, which permits bundling and redistribution.
They are here because the social card is rasterised with Pillow on a slim
Debian container that ships no fonts at all, so the card cannot rely on
anything being installed.

- `JetBrainsMono-Regular.ttf` - JetBrains Mono, (c) The JetBrains Mono Project Authors. See `OFL-JetBrainsMono.txt`.
- `Newsreader.ttf` - Newsreader, (c) The Newsreader Project Authors. Variable weight axis. See `OFL-Newsreader.txt`.

The web pages themselves use system fonts and load neither of these.
